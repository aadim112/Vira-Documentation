## System Requirements

Before installation, make sure your system meets the following minimum specifications:

| Component        | Recommended Version            | Description                 |
| ---------------- | ------------------------------ | --------------------------- |
| Operating System | Windows 10/11 or Ubuntu 20.04+ | 64-bit OS required          |
| Node.js          | 18.x or higher                 | Required for React app      |
| npm              | 9.x or higher                  | Node package manager        |
| Python           | 3.8 or higher                  | Used for AirSim client API  |
| Visual Studio    | 2019 or later                  | Required for Windows builds |
| Unreal Engine    | 4.27 or higher                 | For AirSim simulation       |

## Installing the Project

### Step 1: Clone the Repository

Use the following command to clone the project repository to your local machine:

```bash
git clone <your-project-repo-url>
cd <project-directory>
```
